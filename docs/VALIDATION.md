The initial JUCE configuration failure was missing C-language enablement, followed by absent Linux development headers. CMake now enables C and C++; signed Debian packages are extracted into a local development prefix. Debian's preconfigured snapshot destination returned HTTP 403, so local setup uses the official signed `deb.debian.org` repository without altering system sources or weakening verification. WebKit/CURL features are disabled because this instrument does not use them. ALSA header warnings are from system dependency headers.

Images generated by current tests are ignored outputs: `build/synth-editor.png` and `SpiralExplorer/test-results/spiral-desktop.png` / `spiral-mobile.png`. The editor image is truncated and rewritten on each run to avoid stale results. Sources, CMake, package manifests/lockfile and documentation remain available as uncommitted changes for review; generated builds and dependencies are excluded.

## Not verified here

- Windows x64 compilation with Visual Studio 2026, VST3 loading in FL Studio, automation/state under that host, and offline host rendering.
- Physical audio/MIDI devices, audible output quality, device latency and hard real-time performance.
- Native file chooser interaction and native window management on a real display. The native editor check is an offscreen render, not an interactive desktop session.
- Accurate f₀ for arbitrary polyphonic, noisy or unvoiced audio. Tests use known monophonic fixtures; documented analysis limitations apply.
- Sound reconstruction, learned/AI morphing, installers, signing and distribution. These are not implemented.
- Publication/restoration into a fresh cloud task. Installation and startup fields are saved in a draft; publication is the user's environment-settings action.

Use the Windows instructions and FL Studio checklist in the README to complete platform/host verification. Review and save the environment draft in settings, then publish the prepared environment when desired.
